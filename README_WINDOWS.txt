BARRIEREFREIES WÖRTERBUCH – WINDOWS-VERSION 1.0.0
==================================================

START
-----
Installierte Ausgabe:
1. Den Installer doppelklicken und den Anweisungen folgen.
2. Das Wörterbuch über das Startmenü öffnen.

Portable Ausgabe:
1. Den gesamten ZIP-Ordner entpacken.
2. Barrierefreies_Woerterbuch.exe doppelklicken.

Der Installer richtet das Programm nur für den aktuellen Windows-Benutzer ein
und benötigt deshalb keine Administratorrechte. Alternativ kann die portable
ZIP-Ausgabe ohne Installation verwendet werden. Das Wörterbuch und seine
vollständige Datenbank funktionieren ohne Internet. Nur das freiwillige Öffnen
eines Quellenlinks benötigt eine Internetverbindung und öffnet den
Standardbrowser.

WICHTIG: Den Ordner nicht auseinandernehmen. Die EXE benötigt die beiliegenden
Dateien und den Unterordner "web".

PRÜFUNG UND FREIGABE
--------------------
Die vorangegangene Windows-Version 0.9.0 hat alle 26 Punkte des JAWS-
Testprotokolls bestanden und wurde von einem Fachspezialisten sehr positiv
beurteilt. Version 1.0.0 übernimmt diese geprüfte Bedienung unverändert.

Neu in Version 1.0.0:

- Worttrennungen werden mit Bindestrichen angezeigt, zum Beispiel Ka-rus-sell.
- Das Windows-App-Symbol besitzt einen gut erkennbaren gelben Hintergrund.
- Unter dem Programmtitel steht die kurze Versionsangabe ohne Punkt am Schluss.
- Fenstergrösse und maximierter Zustand werden beim nächsten Start
  wiederhergestellt.
- Zusätzlich zur portablen ZIP-Ausgabe steht ein Windows-Installer mit
  Startmenüeintrag und Deinstallationsmöglichkeit bereit.

Das beiliegende JAWS_TESTPROTOKOLL_WINDOWS_1_0_0.txt dient der abschliessenden
Kontrolle dieser Änderungen und der wichtigsten Bedienabläufe.

SYSTEM
------
- Windows 10 oder Windows 11, 64 Bit
- Microsoft Edge WebView2 Runtime

WebView2 ist Bestandteil von Windows 11 und auf den meisten aktuellen
Windows-10-PCs bereits vorhanden. Fehlt die Laufzeit, zeigt das Programm eine
verständliche Meldung an. In diesem Fall Windows beziehungsweise Microsoft Edge
aktualisieren und danach erneut starten.

BEDIENUNG
---------
Enter:             Suchen
Escape oder Alt+S: Fokus ins Suchfeld
Alt+E:             Einstellungen
Alt+G:             Grammatik
Alt+F:             Wortformen
Alt+W:             Worttrennung
Alt+B:             Bedeutungen
Alt+Y:             Synonyme
Alt+H:             Herkunft
Alt+P:             Beispiele
Alt+R:             Redewendungen
Alt+K:             Charakteristische Wortkombinationen
Alt+D:             Wortbildungen
Alt+Q:             Quellen

Mit JAWS sind sichtbare Rubriken zusätzlich mit H als Überschriften erreichbar.
Alt+F4 schliesst das Programm.
